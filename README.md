# Bioinfo — previsão de malária

Notebook de análise e previsão mensal de casos autóctones de malária em Breves, Pará.

## Configuração

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

No VS Code/Jupyter, selecione o kernel **Python (.venv)**.

## Dados

O notebook procura o CSV `6- Autóctones Mun Fx Etária e Sexo_Dados completos_data.csv` na pasta `~/Downloads` ou no diretório de trabalho. O arquivo de dados não é incluído neste repositório.
