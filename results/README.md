# Resultados

Cada experimento recebe uma pasta própria (`Teste1`, `Teste2` etc.) com previsões, métricas, configurações e gráficos. O código evita sobrescrever uma pasta que já contém resultados; use outro nome para cada execução. Artefatos de versões anteriores foram preservados em `legacy_optimizers/` e `legacy_hybrid/`, e não devem ser misturados aos novos.
