# Teste2 — análise de sensibilidade

Espaço reservado para uma execução alternativa, por exemplo `./run.sh Teste2 --train-fraction 0.7`. Compare a estabilidade dos rankings, lembrando que o intervalo de teste e o tamanho do treino mudam. Não escolha a fração com base no melhor resultado observado; o protocolo primário está em [`docs/revisao_e_protocolo.md`](../../docs/revisao_e_protocolo.md).
